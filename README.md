# Support Vector Clustering (SVC)

Apresentação sobre **Clusterização baseada em SVM** (*Support Vector Clustering*), desenvolvida como parte da disciplina de Aprendizado de Máquina na Universidade Federal de Minas Gerais (UFMG).

## Sobre o projeto

Este repositório reúne os slides (em LaTeX/Beamer) e os materiais de apoio da apresentação sobre o método SVC, incluindo:

- Fundamentos: revisão de SVM, truque do kernel e SVDD (*Support Vector Domain Description*)
- O algoritmo SVC: esfera mínima no espaço de características e atribuição de clusters
- Efeito dos hiperparâmetros (kernel e regularização) nos clusters encontrados
- Aplicação ilustrativa em uma base de filmes (considerando apenas as notas)
- Extra: impacto da redução de dimensionalidade nos resultados do SVC
